# AGENTS instructions

## Writing style (hard rule)

All engineering text in this repo must be plain and literal: commit messages, PR titles
and bodies, issue titles and bodies, code comments, CLAUDE.md, and any doc about code,
tests, or process.

- Commit messages use conventional-commit form: `type(scope): what changed`.
  Example: `fix(camera): stop zoom snapping when a pan crosses a face boundary`.
- Say what changed and why in ordinary words. Name the files, functions, and issue
  numbers directly.
- No metaphor, no wordplay, and no game vocabulary (rungs, skies, fences, deeds,
  bites, wardens, etc.) outside actual game content.
- Avoid the "X, not Y" / "it's not X, it's Y" contrast construction.
- Older commits and docs in this repo are NOT style examples. Do not imitate them.
  If surrounding text is cryptic, write plainly anyway.

The evocative voice is allowed only in player-facing game content (flavor text, card
copy, in-game strings) and in the design vision docs listed in this file. Nowhere else.
